### Báo cáo tiến độ thực tập (8 Tuần)

Trang này ghi lại chi tiết các hoạt động, nhiệm vụ và kết quả đạt được trong suốt 8 tuần tham gia kỳ thực tập với đề tài **Xây dựng và triển khai hệ thống Machine Learning end-to-end trên AWS với SageMaker**.

#### Tóm tắt lộ trình 8 tuần

| Tuần | Chủ đề chính | Nội dung công việc cốt lõi |
| :---: | :--- | :--- |
| **Tuần 1** | Tổng quan ML workflow & Hệ sinh thái AWS ML | Tìm hiểu quy trình ML; cấu hình môi trường bảo mật (IAM, S3, SageMaker Studio). |
| **Tuần 2** | Xử lý dữ liệu (Data Preprocessing) | Chuẩn bị, xử lý dữ liệu và trích xuất đặc trưng với SageMaker Processing Jobs. |
| **Tuần 3** | Huấn luyện mô hình (Training Jobs) | Huấn luyện mô hình trên SageMaker; thử nghiệm các built-in algorithms hoặc custom script. |
| **Tuần 4** | Theo dõi thí nghiệm & Tối ưu siêu tham số | Quản lý với SageMaker Experiments; dò tìm cấu hình tối ưu với Automatic Model Tuning (HPO). |
| **Tuần 5** | Quản lý vòng đời mô hình (Model Registry) | Đóng gói, đăng ký mô hình vào SageMaker Model Registry và thiết lập model versioning. |
| **Tuần 6** | Triển khai mô hình (Model Deployment) | Triển khai lên SageMaker Endpoint (real-time inference); tích hợp API Gateway và Lambda. |
| **Tuần 7** | Giám sát mô hình (Model Monitoring) | Thiết lập giám sát với SageMaker Model Monitor và CloudWatch; phát hiện data drift. |
| **Tuần 8** | Tự động hóa Pipeline & Tổng kết | Tự động hoá toàn bộ quy trình với SageMaker Pipelines; hoàn thiện báo cáo và website. |
