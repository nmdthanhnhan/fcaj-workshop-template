### Objectives for Week 1:
* Connect and get acquainted with members of the First Cloud AI Journey (FCAJ).
* Gain an overview of cloud computing and basic AWS services.
* Get started and familiarize yourself with the AWS CLI command-line tool.

* Master the AWS ML ecosystem and set up a secure development environment (IAM).
